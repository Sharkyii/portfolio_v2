# Sockscarving Chatbot

An LLM-powered customer chatbot for Sockscarving, built and deployed on Cloudflare
Workers. It answers shopper questions directly on the storefront, taking on the
manual back-and-forth that used to eat into reporting time — part of the same
chatbot and document-analytics workflow described in the experience section below.

Live on the main site at [sockscarving.in](https://sockscarving.in), or talk to it
directly: [chat here](https://sockscarving-chatbot.chatbot-sockscarving.workers.dev/chat).
